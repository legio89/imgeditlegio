# AI Mobile Photo Studio

Estudio móvil de edición fotográfica mediante inteligencia artificial.

## Objetivo
Editar fotografías existentes utilizando referencias independientes de:

- Rostros e identidad.
- Características físicas.
- Vestuario.
- Poses.
- Escenarios.
- Composición.

## Desarrollo
Versión inicial MVP 0.1.

Prioridad: software gratuito, privacidad y procesamiento sin tokens.
